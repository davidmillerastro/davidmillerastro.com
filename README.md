# David Miller Personal Website

A simple static academic website intended for GitHub Pages.

## Files

- `index.html` — homepage
- `research.html` — research page placeholder
- `publications.html` — publications page placeholder
- `cv.html` — CV page placeholder
- `styles.css` — site styling
- `assets/profile-placeholder.svg` — replace with your photo
- `assets/David_Miller_CV.pdf` — add your CV using this filename

## Personalize

In `index.html`, replace:

- `YOUR_EMAIL_HERE`
- `YOUR_LINKEDIN_URL_HERE`
- `YOUR_ORCID_URL_HERE`
- both biography paragraphs marked `TBD`

Replace `assets/profile-placeholder.svg` with your own image, then update the
image filename in `index.html`. A portrait-oriented image works best.

Add your CV PDF at:

```text
assets/David_Miller_CV.pdf
```

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

GitHub will provide the public website address after deployment.
